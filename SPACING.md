# Пульт отступов и сетки

Все расстояния сайта управляются токенами в `src/styles/global.css` (блок
«ТОКЕНЫ» в `:root`). Числа в компонентах не повторяем — крутим переменную.

## Ручки

| Ручка | Что делает | Обычный диапазон |
|---|---|---|
| `--page-max` | потолок контента | 1280–1440px |
| `--gutter` | боковое поле экран→контент (узкое, full-bleed-ощущение) | 14–26px, ~1.8vw |
| `--section-gap` | верх+низ секции; разрыв между секциями = ×2 | 48–96px |
| `--section-gap-tight` | поджатая секция | 28–56px |
| `--block-gap` | заголовок секции → её контент | 20–40px |

Все резиновые значения — одной строкой `clamp(мобила, резина, десктоп)`,
медиазапросы для отступов не пишем.

## Как пользоваться

- `.container` — ширина + боковые поля; `.section` — вертикальный ритм.
  Компоненты читают только эти классы и токены.
- Точечные отклонения — модификаторами: `.section--tight`,
  `.section--flush-top`, `.section--flush-bottom`, `.section--surface`
  (серая плашка), `.theme-dark` (тёмно-зелёная секция).
- Полноширинное фото — `.bleed` (без полей вообще).

## Ловушки

- **Дыра между секциями = удвоенный `--section-gap`** (низ верхней + верх
  нижней). Нужен разрыв 120px — ставим 60.
- **Расширение `--page-max` разносит вёрстку**: всё без своего потолка
  расползается. Лечить на элементе (`max-width` + `margin-inline:auto`,
  `aspect-ratio` у фото, `minmax(0,1fr)` у grid-колонок), не сеткой.
  После изменения ширины проверять блоки с фото и формой.
- Мера строки — отдельные токены `--measure-*` в `ch`, ставятся на сам
  текстовый элемент (не на контейнер). Подробности — в `DESIGN.md`.

## Перенос на следующий сайт

Скопировать блок токенов из `global.css` + классы `.container` / `.section` /
модификаторы + предохранители (жирность в наборе, капс, буллиты) — и подобрать
значения под макет. Механизм не меняется.
