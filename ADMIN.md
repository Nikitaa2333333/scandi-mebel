# Админка каталога

Адрес: **https://scandi-chair.ru/admin/**

Добавили модель — панель сама кладёт фото и название в репозиторий, GitHub
пересобирает сайт и заливает на хостинг. Обновление видно через 1–2 минуты.

## Как получить токен (один раз)

Панель работает от имени GitHub-токена. Своего сервера у неё нет: пароля,
который можно подобрать, тоже нет — без токена страница ничего не умеет.

1. github.com → аватар → **Settings** → внизу **Developer settings**
2. **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
3. Заполнить:
   - **Token name** — `scandi-admin`
   - **Expiration** — `No expiration` (иначе раз в 90 дней придётся повторять)
   - **Repository access** → *Only select repositories* → `scandi-mebel`
   - **Permissions** → *Repository permissions* → **Contents** → `Read and write`
4. **Generate token**, скопировать строку `github_pat_...` — показывается один раз.
5. Открыть `/admin/`, вставить в поле «Токен GitHub», нажать «Войти».

Токен сохраняется в браузере. На новом устройстве вставить заново; кнопка
«Выйти» стирает его из браузера.

## Что делает панель

- **Добавить модель** — название, необязательное описание, одно или несколько
  фото. Фото пережимаются в браузере: webp, ширина до 1400 px. Гигабайтные
  снимки со смартфона в репозиторий не попадают, поворот по EXIF чинится сам.
- **Убрать модель** — пропадает из каталога. Файлы фотографий остаются в
  репозитории (места почти не занимают, вернуть проще).
- Одна публикация = один коммит = одна сборка.

## Что править руками

Состав каталога — `src/data/models.json`. Формат:

```json
{
  "name": "Осло",
  "desc": "Необязательное описание",
  "photos": ["photos/oslo-1.webp"],
  "wide": true
}
```

`wide` — карточка на две колонки. Сетка каталога трёхколоночная: чтобы в
последнем ряду не было дыры, `(число моделей + число широких)` должно делиться
на 3.
