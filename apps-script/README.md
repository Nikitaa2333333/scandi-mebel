# Приём заявок через Google Apps Script

Заявка с сайта → строка в Google-таблице → сообщение в Telegram.

Почему так, а не напрямую с сайта: скрипт выполняется на серверах Google,
у которых нет проблем с доступом к `api.telegram.org`. Плюс в таблице
остаётся журнал — если Telegram однажды не доставит, заявка не потеряется.

## Установка — один раз, минут пять

### 1. Таблица и скрипт

1. Создать таблицу на [sheets.new](https://sheets.new), назвать «Заявки Scandi».
2. В ней: **Расширения → Apps Script**.
3. Удалить содержимое `Код.gs` и вставить туда весь [Code.gs](Code.gs).
4. Сохранить.

Лист «Заявки» и шапку скрипт создаст сам при первой заявке.

### 2. Токен бота и получатели

**Project Settings** (шестерёнка слева) → **Script Properties** →
добавить две записи:

| Property | Value |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `TELEGRAM_CHAT_IDS` | id получателей через запятую |

Держим их здесь, а не в коде: файл скрипта видит каждый, у кого есть
доступ к таблице.

### 3. Публикация

**Deploy → New deployment** → тип **Web app**:

- **Execute as:** Me
- **Who has access:** **Anyone** ← обязательно, иначе сайт получит отказ

Скопировать выданный URL вида
`https://script.google.com/macros/s/AKfy.../exec`.

Проверить, что живо: открыть этот URL в браузере — должно вернуться
`{"ok":true,"service":"scandi-lead"}`.

### 4. Подключить к сайту

В [.github/workflows/deploy.yml](../.github/workflows/deploy.yml) раскомментировать
строку и подставить свой URL:

```yaml
PUBLIC_LEAD_ENDPOINT: https://script.google.com/macros/s/AKfy.../exec
```

Запушить — форма начнёт слать заявки туда.

## Подводные камни

**Content-type.** Сайт шлёт `text/plain`, хотя внутри JSON. Так надо:
с `application/json` браузер сначала отправляет preflight-запрос OPTIONS,
а Apps Script на него не отвечает — запрос падает на CORS ещё до отправки.
`text/plain` делает запрос «простым», без preflight. Скрипт разбирает
тело сам через `JSON.parse`.

**Каждый получатель должен нажать Start у бота.** Telegram запрещает
ботам писать первыми. Не нажал — сообщения не придут, при этом заявка
всё равно окажется в таблице.

**После правки скрипта нужен новый деплой.** Deploy → Manage deployments →
карандаш → Version: New version. Без этого по старому URL продолжит
работать прежний код.

**Права при первом запуске.** Google попросит подтвердить доступ к таблице
и к внешним запросам. Экран «Google не проверил это приложение» — жать
«Дополнительно» → «Перейти к проекту».
